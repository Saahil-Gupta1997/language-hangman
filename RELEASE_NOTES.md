# 1.0.0rc1 — Desktop release candidate

- Native profile, guest, practice, word-card, report and recovery screens; no browser server.
- Atomic round completion with persistent duplicate protection.
- Versioned saved sessions, including guesses, hints and between-round learning cards.
- Operating-system application-data storage and single-process ownership.
- Staged database upgrades and validated backup/restore with safety copies.
- Scoped profile export/deletion, bounded logs and privacy-safe diagnostics.
- Original 30-word English travel pack, with explicit pending independent review.
- Game difficulty replaces unsupported proficiency framing in the supported UI.
- Reports computed directly from completed game results with stated denominators.
- Windows packaging definitions, installer pipeline and native smoke journey.

This is not a certified final release. Windows GUI/installer execution, educator review
and external learner acceptance remain gates. The source package does not contain a
prebuilt Windows installer. Cloud, ML, bilingual teaching, auto-update and additional
platform certification are outside this release's supported scope.

The older browser implementation is retained only for compatibility/regression work.
