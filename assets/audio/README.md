Local audio assets for Language Learning Hangman.

Current files are generated fallback WAV tones:

- `background_music.wav`
- `correct_guess.wav`
- `wrong_guess.wav`

These can be replaced later with royalty-free or CC0 audio files. Keep the same file names unless you also update `src/ui/media.py`.

Audio is optional. If files are missing or browser playback is blocked, gameplay continues silently.
